# GISS 366 Midterm Practical Exercises
This repository hosts an editable example for the GISS366 midterm practical. 


---

All maps are hosted via **GitHub Pages** and open directly in the browser. All files within data folder are sourced from publicly available [New Mexico Resource Geographic Information System](https://rgis.unm.edu/), accessed 09/29/2026.

The popul_byco2018.geojson layer has two primary attributes that this organization in this scenario wants you to test. Make sure you can verify these within the GeoJson before altering any pop-up fields. 

| FieldName | Description |
|-----|-------------|
|`cowntee_NA`| Name of the county |
|`popul_byco`| Population by county based on metadata collection |
